# Test-repo

A personal archive of LeetCode solutions written in Python and C++.

This repository is directly linked to my LeetCode practice and is used to record problems I solve, study solutions, and track progress over time.

## Structure

- python/    — Python solutions (one file per problem)
- cpp/       — C++ solutions (one file per problem)
- solutions/ — organized by difficulty/problem (optional)
- README.md  — this file

## File naming convention

Use a consistent filename pattern so files are easy to browse and sort:

- Python: `p{number}_{slug}.py`  (e.g. `p1_two_sum.py`)
- C++:    `p{number}_{slug}.cpp` (e.g. `p1_two_sum.cpp`)

At the top of each solution file include a short header comment with:
- Problem title
- LeetCode URL
- Difficulty (Easy / Medium / Hard)
- Date solved (YYYY-MM-DD)

## Running solutions

- Python: `python python/p1_two_sum.py` (or run with your preferred test harness)
- C++: `g++ -std=c++17 cpp/p1_two_sum.cpp -O2 -o p1 && ./p1`

## Tips for keeping this repo useful

- Commit each solved problem with a clear message (e.g. `Add p1_two_sum (Python)`).
- Keep commits small and focused so your contribution history reflects real progress.
- Add brief explanations or complexity notes in the file header or a solutions README.
